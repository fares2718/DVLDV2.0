# Sprint 7 – Detention & International License

**Duration**: 2 weeks  
**Depends on**: Sprint 6

## Goals

Complete the remaining core operational services.

## User Stories / Tasks

1. Detain a license (fine, reason, date).
2. Release a detained license (via application + payment of fine).
3. Issue International License (only for eligible Class 3 holders).
4. Cancel previous active International License when issuing a new one.
5. Keep full history of International Licenses.
6. Inquiry screens show detention status and international licenses.

## Technical Deliverables

- Detention aggregate
- InternationalLicense aggregate
- Full workflows + validations
- Updated inquiry views

## Definition of Done

- All 7 original services of the requirements document are fully implemented under the new design
