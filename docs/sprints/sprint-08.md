# Sprint 8 – Hardening, Security & UAT

**Duration**: 2 weeks  
**Depends on**: Sprint 7

## Goals

Make the system ready for internal production use by the department.

## User Stories / Tasks

1. Fine-grained permissions on every screen and action.
2. Basic operational reports (applications by type/status, licenses issued, etc.).
3. Performance review of main queries (search by NationalID, license inquiry).
4. Security review (authentication, authorisation, audit completeness).
5. User Acceptance Testing with real department staff.
6. Bug fixing from UAT.
7. Final documentation update.

## Technical Deliverables

- Permission matrix implemented
- Report screens or exportable data
- UAT sign-off document
- Production deployment checklist

## Definition of Done

- Department can stop using the old desktop application for daily work
- No critical or high-severity bugs open
- Audit trail is complete and usable

---

After Sprint 8 the system is considered **Phase 1 MVP complete**.  
Subsequent sprints focus on stabilisation, document management, notifications, and preparation for Phase 2.
